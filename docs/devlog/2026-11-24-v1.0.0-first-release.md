# v1.0.0：把日历插件从零做出来并装上

## 目标

在 DSH 里要一个能用的日程插件：日历、事件增删改、应用内提醒、可选课表、一句话排期、长期规划。
最终要能从 DSH 插件库安装，并且开源。

## 做了什么

- 用 6+3 个问题把需求钉死（见下"关键决定"），避免边做边改。
- 一个 npm 包两个半侧：
  - 宿主 `src/index.ts` + 8 个模块，纯 cordis 函数式插件，**零 `@deepseek-ai/*` import**，
    只用 `ctx.webServer.register` 挂 24 条路由，信封 `{ok,value}|{ok,error}`。
  - 客户端 `src/client/*`，CJS 包一层 `window.__ModuleLoader__.load({id, factory})`，
    React 18 从冻结模块表取；占三个 slot：`sidebar.panellist` / `main` / `shell.overlay`。
- 存储：单文档 `calendar.json`，150ms 防抖 + tmp→rename 原子写，损坏文件改名 `.broken-<ts>`。
- 提醒：`ReminderEngine` 15s tick，12h 回看、30min 过期、静音时段。
- 重复：daily / weekly-weekdays / monthly / weekdays / biweekly，occurrence key `${eventId}@${stamp}`。
- 课表**与日历完全独立**（用户明确要求，不要联动）。
- ICS 导入导出、JSON 备份、中英双语 UI。
- `scripts/doctor.mjs` 11 项自检；6 个测试套件。

## 为什么

- 零 `@deepseek-ai/*` import：宿主半侧以裸 ESM 被加载，外部包解析不保证存在；
  一旦 import 了宿主私有包，插件会在别人机器上直接崩。
- 单文档而不是 SQLite：数据量小（几百条），整份读进内存最简单，也能被用户直接备份/查看。
- 课表独立：课表是"每周固定不变"，日历是"一次性事件"，混在一起会让重复展开逻辑互相污染。

## 踩到的坑

1. **工作区 ACL 拒绝写入**（`SetNamedSecurityInfoW … grantWrite` 失败）：用
   `diagnose-windows-sandbox-acl.ps1 -ExecutionPolicy Bypass` 修好并确认 WRITE_DAC/WRITE_OWNER 已授予。
2. **esbuild 经 npm script 一律 `EPERM spawn`**：改为直接调
   `node_modules/@esbuild/win32-x64/esbuild.exe`；npm 一律带 `--cache E:/Dsh_Schedule/.npm-cache`。
3. **插件装了但不生效**：CLI 被 `package.json.lock`（PID 21384 持有）卡住 → 改用 junction + 手改
   profile 的 `package.json`。另外 bundle 列表是**启动时快照**，改完必须重启应用。
4. **中文桌面显示英文**：`document.documentElement.lang` 缺失、`navigator.language` 是 OS 语言。
   改为 `inject: ['slots','locale']` + `ctx.locale.getLocale().active` + `useSyncExternalStore`。
5. **静音时段被抑制的提醒重启后重放**：补 `recorded` 持久化标记 + 回归测试。
6. **Git 推送全线失败**：旧代理 7890 已死、schannel `SEC_E_NO_CREDENTIALS`、askpass shell helper
   报 `couldn't create signal pipe, Win32 error 5`。可用组合：
   `"/c/Program Files/Git/cmd/git.exe" -c http.proxy=http://127.0.0.1:7897 -c https.proxy=… \
    -c http.sslBackend=openssl -c http.sslCAInfo="C:/Program Files/Git/usr/ssl/certs/ca-bundle.crt"`，
   配 `GIT_ASKPASS` 指向 `.tmp/askpass.cmd`（`@echo off` + `echo %GH_TOKEN%`），推完即删。
7. **提交作者是 `<noreply@localhost>`**：设 `user.name Ray832` / `user.email Ray832@users.noreply.github.com`，
   再 `GIT_SEQUENCE_EDITOR=: git rebase --root --exec "git commit --amend --no-edit --reset-author"` 全量改写。
