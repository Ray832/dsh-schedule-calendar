# 使用说明

插件的入口在左侧栏的「日程」。三个页签，右上角 ⚙ 是设置。

## 日历

- 顶部 `‹ 今天 ›` 翻页，右侧 `月 / 周 / 日` 切换视图，`+ 新建` 建日程。
- 月视图里点某一天选中它，双击直接在那天新建。
- 点已有日程可以改标题、时间、地点、备注、颜色、提醒提前量和重复规则。
- 重复支持：不重复、每天、工作日、每周几、每两周、每月；「重复截止」留空表示一直重复。
- 重复日程的修改会应用到**所有场次**（暂不支持只改某一次）。

## 一句话添加

日历页顶部的输入框，例如：

```
明天下午三点组会，提前十分钟提醒
每周一三五早上八点英语听力，到 12 月底
下周三交实验报告（全天）
```

点「解析」→ 模型返回候选日程 → 确认后才会写入。结果不对就改措辞重来，预览阶段不会落库。

## 在对话里读写日程

不用回到插件页面，直接跟 DSH 说就行：

```
接下来我有哪些安排？
这周还有什么没做完的？
帮我把下周三下午两点的组会排进日程，提前十分钟提醒
把「期末复习」拆成三个阶段，每两周一个，分别排到日历里
删掉下周三那个会
```

**问安排**：模型会用 `calendar_list` 读取你指定区间内的日程（含重复日程的每一场），再据实回答；「接下来」这种没有明确区间的问法，它默认从今天看到大约一个月后。

**加日程**：模型先复述它准备写入的内容跟你确认，然后弹授权框（列出标题和时间）。点允许才写入，拒绝或取消则什么都不写。

**删日程**：模型先读一遍拿到 id，再弹授权框列出「即将删除的日程」。删除作用于整条日程，重复日程会连同所有场次一起删掉，不可撤销。

写入/删除之后，日历页会在几秒内自动刷新。

## 提醒

- 每条日程可以设多个提前量（准时 / 5 / 10 / 30 / 60 分钟），各自触发一次。
- 到点弹出右下角浮层：`完成` 直接打勾，`5 分钟后` / `10 分钟后` 稍后再说。
- 设置里可以开提示音和系统通知；环境没有通知权限时会提示，应用内提醒照常工作。
- 免打扰时段内不打扰，但会被记为"已处理"，重启后不会补发。
- 应用关着的时候到点的提醒，下次打开会补发最多 5 条，标成「错过的提醒」。

## 课表

默认关闭，设置里打开「启用课表」后左侧栏才会出现课表页。

1. **先配学期**：设置 → 课表 → 填「开学第一周的周一」、总周数、每节课的起止时间（默认 12 节，可增删）。
2. **再录课程**，三种方式：
   - 课表页 → `导入` → 粘贴教务系统复制的文字 → `AI 解析这段文本`；
   - `导入` → `选择 CSV 文件`（列顺序见对话框里的「CSV 列格式」）；
   - 直接点空白格子手填：名称、教师、地点、星期、第几节到第几节、周次范围、单双周。
3. 顶部 `‹ 本周 ›` 切周；非本周的课不显示，单双周按当前周自动过滤。

课表与日历互相独立：课程不会出现在日历里（这是刻意的，避免日历被课表塞满）。

## 长期规划

「规划」页签 → `+ 新建目标`：

- 目标名 + 说明 + 截止日 + 优先级；
- 里程碑一条条加，各有自己的截止日；
- 详情页勾选里程碑，进度条自动走；全部勾完自动标记完成。

## 数据与迁移

设置 → 数据：

- `导出 ICS`：通用日历格式，可导入手机日历、Google Calendar、Outlook；
- `导入 ICS`：把别的日历合并进来（不会覆盖已有的）；
- `导出备份` / `恢复备份`：完整 JSON，含课表、目标、设置。

数据文件只有一个：`<DSH_HOME>/storages/dsh-schedule-calendar/calendar.json`，跨工作区共享。

## 出问题时

```bash
npm run doctor
```

会逐条检查：profile 清单、插件列表、能否解析、构建是否最新、宿主端有没有挂载过。哪一步 FAIL 就按提示处理。
